# 🎙️ Terra à Parte — Podcast

## 🧠 Sobre o Projeto
Este projeto apresenta a criação e organização de um podcast focado em temas relevantes e atuais.
O objetivo é explorar ideias, reflexões e discussões através de conteúdo em áudio, com apoio de ferramentas de Inteligência Artificial no processo de roteirização e organização de conteúdo.

## 🎯 Objetivo
- Desenvolver um projeto de podcast do zero
- Organizar conteúdo de forma estruturada (roteiros, temas, episódios)
- Utilizar ferramentas digitais e de IA para produção e planejamento

## 🚀 Conteúdo
- Roteiro do episódio piloto
- Estrutura e planejamento do projeto
- Ideias e temas para próximos episódios

## 🛠️ Ferramentas utilizadas
- GitHub
- Ferramentas de gravação e edição de áudio
- Inteligência Artificial (apoio na criação e organização do roteiro)
